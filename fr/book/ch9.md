# Chapitre 9 : Mettre à jour une installation XOOPS existante — Archivé (XOOPS 2.5.x)

> **⚠ Avertissement — contenu archivé**
>
> Cette page décrit une procédure de mise à jour de l'époque XOOPS 2.5.2. Elle **n'est pas** maintenue pour XOOPS 2.7.0. En particulier, l'**étape obligatoire** de pré-vérification Smarty 4 (`upgrade/preflight.php`) pour 2.7.0 est absente ; sans ce contrôle, l'outil de mise à jour refuse de continuer.
>
> **Pour mettre à jour vers XOOPS 2.7.0, utilisez la version anglaise de référence à la racine de ce dépôt : [chapter-9-upgrade-existing-xoops-installation.md](../../chapter-9-upgrade-existing-xoops-installation.md).**
>
> Le contenu original 2.5.2 de ce fichier reste disponible dans l'historique git.
