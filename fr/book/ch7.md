# Chapitre 7 : Paramètres d'administration — Archivé (XOOPS 2.5.x)

> **⚠ Avertissement — contenu archivé**
>
> Cette page faisait partie de l'ancienne version française du Guide d'installation XOOPS pour XOOPS 2.5.x. Elle **n'est pas** maintenue pour XOOPS 2.7.0. Changements importants de 2.7.0 absents de la page d'origine : indicateur de force de mot de passe basé sur zxcvbn, validation d'e-mail via `FILTER_VALIDATE_EMAIL`, nouveaux thèmes (`xbootstrap5`, `xswatch4`/par défaut, `xswatch5`, `xtailwind`, `xtailwind2`), nouveau module `debugbar`, fichier de licence désormais sous `xoops_data/data/license.php`. La description du thème « Zetagenesis » dans le texte d'origine n'est plus exacte.
>
> **Pour XOOPS 2.7.0, utilisez la version anglaise de référence à la racine de ce dépôt : [chapter-7-administration-settings.md](../../chapter-7-administration-settings.md).**
>
> Le contenu original 2.5.x de ce fichier reste disponible dans l'historique git.
